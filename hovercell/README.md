# Hover Cell Studio v4

GitHub Pages-ready hover message/card maker.

- 15 cover presets
- Multiple photos
- Per-photo timing and drag reorder
- Hover effects and particles
- Large fullscreen preview modal
- Preview zoom +/- and mouse-wheel zoom
- Fullscreen button
- ESC / backdrop close

Upload these files to the `hovercell` folder in your GitHub Pages repository.


### 표지 디자인 개선
표지 프리셋은 이제 색상/문구만 바꾸는 공통 템플릿이 아니라, 각 테마에 맞는 독립 일러스트(SVG)를 사용합니다. 러브레터는 편지/봉투, 벚꽃은 벚꽃나무, 달빛은 달/밤하늘, 리본은 선물 상자, 엔젤은 날개, 오로라는 오로라, 크리스탈은 보석, 버터플라이는 나비, 가든은 꽃밭, 빈티지는 편지지, 로열은 왕관, 스위트는 케이크, 뮤직은 음표, 매직은 마법진, 폴라로이드는 사진 프레임 형태로 서로 다르게 구성됩니다.
