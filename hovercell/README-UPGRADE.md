# Hover Cell Studio 업그레이드 버전

기존 호버방셀 제작툴을 기반으로 UI와 효과를 확장한 버전입니다.

### 추가된 기능
- 로맨스 / 나이트 / 페어리 / 빈티지 샘플 테마
- 5종 공개 애니메이션: 소프트, 줌+블러, 슬라이드, 와이프, 3D 플립
- 둥둥 / 빛 반사 / 글로우 / 파티클 / 3D 마우스 틸트
- 별 / 하트 / 꽃 / 버블 파티클
- 효과 강도 / 속도 / 모서리 조절
- 고급형 편집 UI와 실시간 미리보기
- 기존 HTML / 파일 분리 export 유지
- 모바일 탭 동작 및 reduced-motion 대응
